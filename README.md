# 💄 GoGlam — Virtual Makeup Try-On App

GoGlam is an AI-powered virtual makeup try-on web app that lets users preview makeup looks in real-time. Built using React.js (with Vite), styled with Tailwind CSS and ShadCN UI components, and powered by Supabase for authentication and backend services.

---

## ✨ Tech Stack

- ⚛️ React.js + Vite
- 🧠 TypeScript
- 🐬 Supabase (Auth + DB + Storage)
- 🎨 Tailwind CSS
- 💎 ShadCN UI
- 🧪 ESLint + Prettier (code quality)
